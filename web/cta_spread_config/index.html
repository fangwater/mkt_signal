CTA Spread 信号

全局默认开多、开空、退多、退空分位和 价差过滤。同向保持原 qty；退出保留现货、以合约对冲；反向信号通过过滤时直接反转。保存后约 1 秒生效，下一根新闭合 bar 使用新设置。执行参数由 CTA Manager 管理。
期现价差：过滤现货开仓方向

spread = (现货 mid − 永续 mid) / 现货 mid。两市场按同一闭合分钟配对；2880 个分钟槽位，至少 1440 个有效样本；开仓使用前一分钟的价差分位。

所有开仓都在现货，并同时通过 NQ 与价差过滤。默认多头要求 NQ 分位 ≥ 0.5、价差分位 < 0.7；空头要求 NQ 分位 ≤ 0.5、价差分位 > 0.3。价差 0.3–0.7 区间可放行两种方向，最终由各自因子及 NQ 决定；任一过滤缺失或未预热均不入场。

价差不触发退出。因子退出时保留现货，合约目标为现货数量的相反数。反向因子同时通过 NQ 与价差过滤时直接发布反转后的完整目标；未通过时只退出旧方向。

币种阈值 JSON

按 symbol 单独配置因子开仓、平仓阈值和 NQ 开仓过滤阈值。省略字段或填 null 继承全局值，删除币种恢复全局设置；与上方参数一起保存，下一根新闭合 bar 生效。NQ 分位范围 [0, 1]。也可覆盖 spread_long_quantile、spread_short_quantile 价差过滤阈值。

JSON 示例（字段可按需省略）
{
  "BTCUSDT": {
    "factor_long_quantile": 0.95,
    "factor_short_quantile": 0.05,
    "factor_exit_quantile_long": 0.4,
    "factor_exit_quantile_short": 0.6,
    "nq_long_quantile": 0.65,
    "nq_short_quantile": 0.35
  }
}

币种与独立因子策略

整份 JSON 配置 symbol → factor → 方向。负数反转因子方向，正数保持方向，0 停用。每个策略独立形成满多、满空、空仓三种状态；数值幅度不参与仓位分配。保存时检查币种、因子和数值；不通过不会覆盖配置。交易开关关闭时只计算和观察信号。

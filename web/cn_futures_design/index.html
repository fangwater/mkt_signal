A

一个明确的路由

每个实例绑定账户、交易后端和交易所白名单。CTP 与易达各自原生接入；连接异常时暂停新开仓，不跨柜台自动改投。

B

一个完整的交易意图

合约、方向、开平、手数、价格 tick、有效方式。柜台错误码、原始订单及成交标识随事件保留。

C

易达的接入边界

官网的“资金与持仓计算兼容 CTP”不能证明 API / ABI 兼容。已按公开原生 SDK 参考实现；正式接入需核对期货公司配套版本。

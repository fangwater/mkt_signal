CTA Perp 信号

设置全局开多、开空、退多、退空阈值和 NQ；下方 JSON 可按币种覆盖开平阈值和 NQ 阈值。 满多、满空、空仓三个状态，同向信号保持原 qty。保存后约 1 秒生效，下一根新闭合 bar 使用新设置。执行参数由 CTA Manager 管理。
NQ change：按最终方向过滤开仓

每币独立计算，P 取本合约每分钟最后一个有效盘口 mid = (买一 + 卖一) / 2。

BUY_NQ = (P − 最近 2h 最低 mid) / 最低 mid；SELL_NQ = (P − 最近 2h 最高 mid) / 最高 mid。

价格极值和 NQ 分位均使用 120 个分钟槽位，包含当前值；缺失值不参与统计，NQ 至少 60 个有效样本才就绪。分位采用相同值的中间排名。

单个因子决定做多时，BUY_NQ 分位 ≥ 多头阈值才放行；做空时，SELL_NQ 分位 ≤ 空头阈值才放行。默认 0.5 表示历史分位 50%。

NQ 未就绪或未通过时拦截开仓；关闭后跳过此过滤。NQ 只过滤各因子的开仓，不拦截退出。

百分位用法：v0 直接使用 x，范围 [0, 1]；v1 使用 2x − 1，范围 [−1, 1]，例如 80% → 60%。四个开平阈值直接比较该算法的结果，切换算法不会自动换算阈值。v1 等待全部启用因子到齐同一根分钟后取等权算术平均，再比较开平阈值；NQ 使用原分位数。切换算法需先关闭现有仓位。

币种阈值 JSON

按 symbol 单独配置因子开仓、平仓阈值和 NQ 开仓过滤阈值。省略字段或填 null 继承全局值，删除币种恢复全局设置；与上方参数一起保存，下一根新闭合 bar 生效。NQ 分位范围 [0, 1]。5m NQ 仍固定使用 Q50，不支持修改 NQ 分位阈值。

JSON 示例（字段可按需省略）
{
  "BTCUSDT": {
    "factor_long_quantile": 0.95,
    "factor_short_quantile": 0.05,
    "factor_exit_quantile_long": 0.4,
    "factor_exit_quantile_short": 0.6,
    "nq_long_quantile": 0.65,
    "nq_short_quantile": 0.35
  }
}

币种与因子

整份 JSON 配置 symbol → factor → 方向。负数反转因子方向，正数保持方向，0 停用。每个因子独立形成满多、满空、空仓三种状态；数值幅度不参与仓位分配。保存时检查币种、因子和数值；不通过不会覆盖配置。交易开关关闭时只计算和观察信号。

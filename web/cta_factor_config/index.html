按标的覆盖阈值 / 均值模式 NQ 参数

独立持仓按每行的 NQ 条件判断；均值模式要求同一组合使用共同的 NQ 条件。额度在两种聚合方式下分别按因子、按标的使用。每个策略组的各频段独立配置额度和开关；组内同频段的子仓位按币种汇总，向 Manager 发布为一份策略。相同因子计算在组间共享，仓位分别持久化。

A process manager built in Rust inspired by PM2

Usage: pmdaemon [OPTIONS] <COMMAND>

Commands:
  start               Start a process
  stop                Stop a process
  restart             Restart a process
  reload              Reload a process (graceful restart)
  delete              Delete a process
  list                List all processes
  monit               Monitor processes in real-time
  logs                Show process logs
  info                Show process information
  web                 Start web monitoring server
  regenerate-api-key  Regenerate the API key
  show-api-key        Show the current API key
  help                Print this message or the help of the given subcommand(s)

Options:
  -v, --verbose          Enable verbose logging
  -c, --config <CONFIG>  Configuration file path
  -h, --help             Print help
  -V, --version          Print version

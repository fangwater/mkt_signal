# Gate FR arb03、Bybit FR arb01 与 CTA Manager 盈亏口径

## 计算口径

Gate、Bybit 的 funding_rate 来源均由 crypto_nav_manager 的数量 FIFO 引擎计算，现货和合约各自独立 FIFO 后相加。CTA Manager 从 NAV 的只读 HTTP 接口获取 FR 结果，不另外计算一个只含资金费的 Gate 收益。

- FR 首页“今日盈利”：当日已实现交易盈亏 + 实际资金费 - 交易手续费 - 借贷利息。
- FR“净值”监控曲线：从该监控起点归零的上述已实现净收益累计值。排除未平仓浮盈亏。
- FR 账户“权益”：账户监控器的实际权益，包含未平仓浮盈亏等账户估值因素。
- 本次 Bybit 审计的总 USDT 损益：已实现净收益 + 按现货和合约各自价格估值的浮动损益。

对齐相同起止时间、完整原始成交和期初库存，Bybit 在 11:16 审计快照的已实现净收益应为 -581.57030755 USDT；加浮盈 +63.81118561 USDT，才得到总损益 -517.75912194 USDT。这是按 CTA FR 口径重算的数字，不是声称当前页面显示该数；当前 Bybit 页面仍受去重/起点/历史覆盖问题影响。

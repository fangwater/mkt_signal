## 手工交易与操作偏差

非 BNB 实际净敞口绝对值合计从127.1602降至8.2882 USDT，剩余各项低于交易所
最小数量或最小名义金额。42笔永续市价订单对应47条成交，全部为taker；累计
成交名义金额118.78187210 USDT，手续费0.03563438 USDT。
其中36笔订单低于5 USDT：本次未沿用既有脚本默认5 USDT清理阈值，处理粒度过细，
不能将47条成交解释为大额敞口或47次下单。后续没有继续手工追逐尾差。

最初错误地将 BNB 手续费利息负债纳入对齐，提交并成交 BNBUSDT BUY 0.13，
订单98292911854，均价673.51，2条taker成交，手续费0.02626689 USDT。
操作前BNB合约仓位为0。首次订单查询暂时返回400，后续按client ID、持仓和成交
三方复核确认成交；未重复提交。向用户说明后，用户明确选择暂时保留该0.13多仓，
不再操作BNB。此后BNB未再下单；BNB默认排除要求已补入AGENTS.md。
不能把这一笔误操作算作用户授权的正常敞口清理。

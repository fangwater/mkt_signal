# 原生成交回报来源

Manager 净值和策略归因必须区分实时成交回报与恢复阶段首次发现的历史成交。
`normalized_trade` 审计记录保留事实身份，并增加 `origin`：

- `live_report`：CTP 已完成会话恢复后的实时 TRADE 回调，或易达明确非 replay 的成交回报。
- `recovery_report`：易达明确 replay 的成交回报。
- `unclassified`：没有足够上下文的规范化成交，包括通用恢复及退出尾部记录。

该字段由柜台适配路径设置，不由策略、Manager 或报单类型推断。成交数量、价格、
原生身份、开平、原始时间及实际手续费的持久化不变。它不代表 Maker/Taker，
也不把本地提交或 SDK 受理标记成成交。

原始回报与 normalized 身份／方向／数量／价格仍须一致。缺少明确来源的旧历史不
回填标签；恢复查询缺少原始 UTC 成交时刻时，不能按查询接收时间当作新成交回放。
已知旧成交在恢复重复出现时，存储继续保留其首次证据序号和接收时间。
